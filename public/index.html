QQ 邮箱设置

请在运行发信助手的电脑上填写。设置由电脑的 Windows 账号加密保存，重启后自动读取。

保存不会发送测试邮件。下一次下单时才会验证授权是否成功。

✉

第一次配置？

  1. 在电脑浏览器登录 QQ 邮箱。
  2. 进入设置，找到第三方客户端或 SMTP 服务。
  3. 按邮箱提示开启服务，生成授权码。
  4. 把授权码填写在左侧，保存即可。

设置一次后，重启可继续使用；以后可修改收件人。不要把授权码发给其他人。
